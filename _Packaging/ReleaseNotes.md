### Changed
- The "Added in" tooltip names Wrath of the Lich King patches more precisely: 3.0.2 is Wrath of the Lich King (pre-patch), 3.2.2 is 5th Anniversary Celebration instead of Call of the Crusade, and 3.3.5 is Defense of the Ruby Sanctum instead of Defending the Ruby Sanctum
- The addon's own category data is now written with the `KrowiAF.NewExpansion` / `NewTabCategory` builder instead of positional tables; nothing a player sees changes (dev note: an argument-order slip in a positional node fails silently, which is how the nineteen categories below went missing. Every file was migrated behind a category-tree snapshot that had to show a zero diff. Plugin-facing: `:Named` no longer merges implicitly and `:Merge()` is explicit, a zone can hold zones, `KrowiAF.NewCategory` builds a detached category and `:WithId(n)` declares an id. The V1 parser stays supported)

### Added
- Debug mode prints, after login, what the data load skipped or dropped (dev note: the data layer only knew a silent skip or a fatal assert, which is how nineteen categories vanished unnoticed. Every drop site now reports to `addon.Data.LoadDiagnostics`; the offline lint reads the same table, fails on a drop site that does not report, and reports a version cutoff at a patch the client has not reached)
- Plugins can attach to a category by a stable key: the category declares `:Key("MyAddon.MyCategory")` and `KrowiAF.NewInjection` accepts that key as well as a category id (dev note: auto-allocated category ids are parse positions that shift when a data file is reordered and were never safe to target. A key costs no id and lets a per-client subtree attach to a category a Shared file builds; see `Api/ApiDocumentation.lua`)

### Fixed
- Veteran of the Shifting Sands and Agent of the Shen'dralar are now marked never obtainable on Retail, as on Classic, instead of temporarily obtainable until 4.0.3 (dev note: both feats of strength were added in or after 4.0.3 and granted retroactively for reputation earned before Cataclysm, so a `Before 4.0.3` cutoff described an empty window)
- A Round on the House in Midnight is now marked as obtainable only during Brewfest, like its Dragon Isles and Khaz Algar counterparts
- Mists of Pandaria Classic: the seasonal Challenge Mode achievements now follow their seasons. Challenge Conqueror: Platinum (Season 1) is no longer obtainable, the Season 2 achievement and its Realm First! end with 5.5.4, and the Season 3 ones are Time Limited until the patch after 5.5.4 (dev note: none of them had a cutoff, so all showed as permanently obtainable. Season 1 ended with 5.5.3, the patch that added its achievement, so it is marked Never; Season 3 has no announced end, so its cutoff is the next Classic version whenever it comes)
- The obtainable tooltip of seven achievements named their cutoff as a bare version code, such as "Version 070105", instead of the patch: I Can't Hear You Over the Sound of How Awesome I Am, Bottle Service (Season 2), Cutting Edge and Ahead of the Curve: Xavius, Two Minutes to Midnight, Crunching for Cultists and It's Nearly Midnight (dev note: their anchors pointed at 5.0.5, 6.0.3, 7.1.5 and 12.0.1, patches in which no achievement was added and which were therefore never registered. I Can't Hear You Over the Sound of How Awesome I Am now ends with 5.0.4 (`Until`), the other patches are registered, and the build-version filter lists only the patches some achievement was added in, so an anchor-only patch adds no empty checkbox. The data load reports an anchor on an unregistered patch, which is how these surfaced)
- Mists of Pandaria Classic: hovering an achievement popout or its close button raised `attempt to call a nil value`, and the search results box could not tell whether the mouse was still over it (dev note: both checks called `GetMouseFocus` on Classic, which was removed from every client, not only Retail; `GetMouseFoci` is used everywhere now)
- Nineteen categories and their achievements were missing from the Specials and Events tabs on both clients: BlizzCon, Collector's Edition, Overwatch, StarCraft II, Heroes of the Storm, Warcraft III: Reforged and Warcraft Rumble under Promotions, Honor and World under Player vs. Player, and Reputation, Raids and Dungeons under Realm First! and Darkmoon Faire (dev note: the nodes had `canMerge` before the name; the V1 parser matches no branch for a leading boolean and drops the node without a word. The repo lint now catches the shape)
- Mists of Pandaria Classic: achievements that Retail removed in Warlords of Draenor or a later expansion are no longer marked temporarily obtainable, which had put 306 of them in the Time Limited category with tooltips reading "up until the start of Version 060002"; and the five Siege of Orgrimmar cutoffs (Eternally in the Vale, Cutting Edge and Ahead of the Curve: Lei Shen, Cutting Edge: Ra-den, Hordebreaker / Darkspear Revolutionary) now end at Classic's own Siege patch, 5.5.4 (dev note: a version cutoff names the patch as Retail shipped it, but it was compared as a plain string against the running client's version, so Mists Classic's 5.5.x sat above every original Mists patch and below everything after. A cutoff now resolves through a per-client table, `DataAddons/Classic/ContentTimeline.lua`, that maps each Retail patch to the patch where Classic reached the same content, `["5.4.0"] = "5.5.4"`; Retail needs none. Content the client has not reached means no end is scheduled here rather than a spurious future cutoff; the tooltip says so. Nothing in the data files changed, and 5.5.4 itself adds only 18 hidden Challenge Mode rating trackers. See `docs/data-design-review.md` §5.1)
- Escape closes the addon's windows one per press, the most recent first, and leaves the windows underneath open, the achievement window included; the Map Verifier closes on Escape; a popup, a context menu or a spell cast that takes the press no longer closes an addon window too; and the Escape press after using a close button is no longer swallowed (dev note: the old `ToggleGameMenu` post-hook ran after every branch of Blizzard's handling, and the `KrowiAF_SpecialFrame` proxy stayed in `UISpecialFrames` after a close button. `Gui/FramesForClosing.lua` now keeps the shown frames in order and closes the most recent from inside `CloseSpecialWindows`. Retail 12.1's `RegisterGameMenuEscHandler` was tried and rejected: registering from addon code taints Blizzard's handler table and every later Escape ran tainted. Covered by the new `escape` test suite)
- The layout options Show Sub Categories and Ignore Filters of the Watch List, Show Sub Categories of the Tracking Achievements and Excluded categories, and Show Excluded Category no longer empty the category and raise a Lua error (dev note: `Options/Layout.lua` still called two loaders removed in 81.0. All rebuild paths now go through the reset functions in `Data/SpecialCategoryAchievements.lua`, which also clear the per-achievement mirror lists so a later unwatch no longer walks an orphaned tree. Covered by the new `special` test suite)
