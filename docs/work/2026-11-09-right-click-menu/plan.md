Spec: [spec.md](spec.md). Status: accepted

## Context
106 splits KAF into a core plus switchable features; Reward preview was the proof of concept (#405). The Right-click menu comes next because other features plug entries into it and Reward preview's entry still closes the menu by name. Krowi's decisions at the design gate (2026-11-09): opener slot plus row-parts slot with the menu fully in its folder; transmog set data stays in the core; the menu of an unregistered achievement is fixed here, test first. ## Risks
- **GW2_UI** skins the row button when a row is first acquired, after `OnLoad`; the part runs inside `OnLoad`, so it is unchanged.
- **Classic:** `menuBuilder:Close()` closes Krowi_Menu's shared root, as `CloseMenu` did; on Retail it is a no-op, as today.
- **Load order:** the core entries add themselves at Gui load (`Slots.lua` loads earlier); the rows are made after `StartAll` (`Krowi_AchievementFilter.lua:39, 57`).
- **Run length:** the matrix doubles to four steps per client.
- **The before-run** on `main` comes after the code exists; if `main` is red there, the build waits.
