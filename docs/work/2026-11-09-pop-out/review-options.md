# Pop Out's settings, reviewed

The review every feature PR of the split makes of its own settings (`docs/backlog.md`, "For the feature split (106)", PR #392), through REVIEW.md's Texts pass: what each does, its name, its description and its help text. Proposals only; Krowi picks at the look gate. The saved keys never change (`Popout.*`, `Achievements.Modifiers.PopOut`), so a pick costs text: a renamed phrase goes into every locale file, translated, and to CurseForge.

The section now reads, top to bottom: **Enable** (new), the heading **Pop Outs** with the modifier and its button to Keys and clicks, then six settings, the sub-heading **Buttons** with two, the sub-heading **Appearance** with three. Most descriptions today start with a noun or "Remember", not a verb that says what changes, and several still say "popped-out achievement window" or "/reload".

| `Achievements.Modifiers.PopOut` | The key held while clicking a row that opens its Pop Out (`Modifier.lua`). Ctrl by default. Help page (`Help Popout Intro`, `Help Popout Close On Earn`): the intro says "Ctrl-click", which is wrong for a player who changed the modifier. Proposal: "Hold the Pop Out modifier (Ctrl unless you changed it) while clicking an achievement to open it in a small window that stays on screen. Drag one Pop Out onto another to stack them." The close-on-earn term follows the setting's name if it changes.

Translations: each picked name or description becomes a new key in all 11 locale files, translated in all ten languages; the old keys leave every locale file and are deleted on CurseForge after the merge, on Krowi's approval. The descriptions that took `{popout}` drop it: the section's own heading names the Pop Out.

## Decision
2026-11-11, at the look gate (gates.md):
- Row 1: the modifier row in Pop Out's section is named **Click Modifier** (Krowi: "name pop out in the popouts section "click modifier""); Keys and clicks keeps **Pop Out**. The description is unchanged.
- Help page: the intro names the key the player set ("Hold {modifier} while clicking ..."), and with None says to set Click Modifier to a key (Krowi: "help says ctrl-click regardless of the pop out modifier"). New phrases `Click Modifier`, `Help Popout Intro {modifier}` and `Help Popout Intro No Modifier` in every locale; `Help Popout Intro` leaves them all and is deleted on CurseForge after the merge, on Krowi's approval.
- Descriptions: Krowi asked for a sweep into plain text ("do a non AI text sweep on the pop out descriptions"), and that each place's modifier row makes sense for its section; the texts in the build are the review page's (https://claude.ai/artifact/Erxm6FLjXJd46kMyJ9NA52), in every locale.
- Names ("ok on all"): Persist Across Sessions → Reopen After Login, Remember Last Position → Open Where Last Moved, Default Width → Starting Width, Close On Earn → Close When Earned (the help page's term too), Close On Earn Delay → Close Delay, Enable Snapping → Snap into Stacks, Auto-Hide Close Button → Close Button on Mouseover, Auto-Hide Resize Button → Resize Button on Mouseover, Fade When Not Hovered → Fade without Mouseover, Fade Speed → Fade Time; Remember Size, Snap Distance and Faded Opacity stay. The old name keys leave every locale file and are deleted on CurseForge after the merge, on Krowi's approval.
